 Property Web — Real Estate Website

A modern, responsive, and visually appealing real estate website built with **React.js** and **Tailwind CSS**. This project is designed to provide a clean, smooth, and professional experience for showcasing properties, projects, company information, testimonials, and contact details.

The website focuses on **modern UI, responsive design, smooth scrolling, reusable React components, and interactive animations**.

🧩 Main Components
🦸 Hero

The hero section introduces the real estate brand with a modern visual layout and clear call-to-action.

📖 About

The About section presents information about the company along with animated statistics such as:

Years of Experience
Projects Completed
Sq. Ft. Delivered
Ongoing Projects

The counters start animating when the user scrolls into the About section.

🏢 Projects

A dedicated section for showcasing real estate projects with a clean and responsive card-based layout.

💬 Testimonials

Displays client feedback and testimonials to build trust and credibility.

📞 Contact

Provides users with an easy way to get in touch with the company.

🧭 Navbar

Responsive navigation with smooth scrolling between different sections of the website.

👣 Footer

Contains important links and additional company information.

🔢 Animated Counter

One of the interactive features of this project is the animated statistics counter.

The counter does not start immediately when the website loads. Instead, it uses the Intersection Observer API to detect when the About section becomes visible.

For example:

0 → 1 → 2 → 3 → ... → 10+

This provides a smoother and more engaging user experience.

🚀 Installation & Setup

Clone the repository:

git clone https://github.com/izafi/property-web.git

Navigate to the project:

cd property-web

Install dependencies:

npm install

Start the development server:

npm run dev

Open the local development URL provided by Vite in your browser.

🏗️ Build for Production

Create a production build:

npm run build

Preview the production build:

npm run preview
